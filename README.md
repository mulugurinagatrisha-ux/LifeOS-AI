# 🤖 LifeOS AI

**LifeOS AI** is an AI-powered personal productivity and life management platform built using **Python Flask**. It helps users organize daily activities, manage goals, track expenses, store notes, monitor weather, and receive AI-powered assistance—all in one modern web application.

---

## 🚀 Features

* 🔐 Secure User Authentication
* 📊 Interactive Dashboard
* 📝 Notes Management
* ✅ Task Management
* 🎯 Goal Tracking
* 📅 Calendar Management
* 💰 Expense Tracker
* 🌦️ Real-Time Weather Updates
* 🤖 AI Chat Assistant
* 🧠 AI Goal Suggestions
* 👤 User Profile Management
* 📱 Responsive Modern UI

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/mulugurinagatrisha-ux/LifeOS-AI.git
```

Go to the project folder

```bash
cd LifeOS-AI
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the virtual environment

### Windows

```bash
venv\Scripts\activate
```

### macOS/Linux

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python run.py
```

Open in your browser

```
http://127.0.0.1:5000
```
